# 扩展能力与开放边界

本文件处理颗粒日记产品中已经存在、但尚未完整开放为 Skills API 的能力。原则：可以解释和路由，不伪造请求。

## 能力矩阵

| 能力 | 状态 | 当前 Agent 行为 |
|------|------|----------------|
| 素材关系图查询/写入/衍生 | planned | 可先查询素材与颗粒；图写入、节点拖动、衍生等待公开契约 |
| 品题 TTQ / CTTQ / IPTTQ | planned | 解释产品流程并引导用户在颗粒日记客户端完成 |
| PAS 上传、识别与刻意练习 | planned | 不用普通 asset 提取冒充 PAS 分析 |
| 颗粒工厂下单与支付 | planned | 引导官方客户端；涉及价格和付款必须二次确认 |
| 掌握日历、收藏、已掌握颗粒读取 | available | 经 learning 流程读取用户自己的快照 |
| 备注、收藏与掌握状态写入、其它学情 | planned | 不声称已写回；可整理待办供用户确认 |
| keliagent 有屏/离屏会话 | limited | 有受信入口时可创建会话；不是通用 API Key Open endpoint |
| OSR 精炼与对话 | limited | 由 keliagent/受信服务调用；不直连 OSR 内部服务 |

## 品题与 PAS 的边界

| | TTQ / 品题 | PAS / 实战答题纸 |
|--|------------|------------------|
| 目标 | 聚合颗粒、发现隐性能力、变式与浓缩 | 从真实落笔痕迹定位错因并练习 |
| 输入 | 已有知识颗粒与品题语境 | 答题纸、源题与书写证据 |
| 输出 | 品题活动、CTTQ、诱导题等 | PAS 记录、错因路径与刻意练习 |
| 禁止 | 接收 PAS 局部练习题作为诱导题库回写 | 用普通素材提取假装完成答题纸分析 |

当用户说“出类似题”时，先确认是基于品题能力做变式，还是基于答题纸痕迹做错因练习。当前两者均无完整公开 Skills 契约，不应退化为通用 LEC 或素材提取后宣称完成。

## 素材关系图

关系图是素材与知识衍生的主工作面。Agent 可以使用已开放的素材和颗粒读取能力帮助用户定位对象，但以下动作在公开契约前均不得声称已执行：

- 写入节点位置或标注；
- 创建图上衍生颗粒；
- 连接、删除或重排关系；
- 更新私人备注。

## keliagent 与 OSR

`keliagent` 是颗粒日记学科闭环的对话运行时，可装载 L0/L1/L2 与 LearnerSession。其会话入口支持 `subject` 和 `surface=screen|offscreen`，但它不是 Gateway `/api/v1/open/*` 的等价物。

使用规则：

1. 只有宿主已经提供受信的 keliagent 入口与身份上下文时才调用。
2. 创建会话时显式携带 subject，不从默认值继承数学。
3. 日记业务写入仍经 Skills Gateway / AppFunctor，不把对话结果当作持久化成功。
4. OSR 内部库存、Shard、Topic 和音频对象保持私有；Agent 不直连 OSR 数据库或内部服务。
5. 通用第三方 Agent 只有 API Key 时，应说明此能力尚未开放，而不是请求服务令牌。

## 颗粒工厂与付费操作

工厂能力由 AppFactory 等业务服务持有。公开 Skills 契约上线前只提供官方客户端路径。未来开放时必须满足：

- 价格来自服务端实时响应；
- 建单前确认商品、学科、数量、价格和付费人；
- 支付、取消和退款属于高影响操作；
- 不保存支付凭证，不用 Agent API Key 代替支付身份。

## 能力升级条件

将 `planned` 或 `limited` 提升为 `available` 前，必须同时具备：

1. Gateway 已发布公开 endpoint；
2. 鉴权与 scope 已定义；
3. self 边界、错误响应和幂等性已验证；
4. 本仓库补充可执行流程与失败恢复；
5. 校验脚本中的 endpoint allowlist 已同步。
